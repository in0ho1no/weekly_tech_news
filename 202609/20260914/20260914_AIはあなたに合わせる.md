# AIはあなたに合わせる

## きっかけ

2026年8月28日、AnthropicがAIの安全性に関する研究結果を公開しました。  
公開されているベンチマークで測定可能な「AIの失敗（問題行動）」を10種類に分類し、それらを減らす訓練方法をAI自身に探させる、という実験です。  

ここで取り上げたいのは実験の詳細な中身ではなく、挙げられている10種類の失敗パターンです。  
そこには、嘘をつくことや制限の回避などに並んで、「sycophancy」（本記事では「迎合」と記載）が含まれています。

今回は、AIの開発側でも修正すべき課題として扱っている「迎合」について整理します。

:::source
・Automated researchers can reliably mitigate alignment failures（Anthropic、2026年8月28日）
<https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures>
・Anthropic、AIに「AIの安全性研究」を任せる実験　うそ、迎合などの問題行動を性能落とさず改善（ITmedia AI＋、2026年8月31日）
<https://www.itmedia.co.jp/aiplus/article/2608/31/2000000964/>
:::

## 迎合とは

### そもそも迎合とは何か

迎合とは、利用者の意見や前提に寄り添い、相手が賛同・納得しやすい答えを返してしまう傾向のことです。

これは、単に「AIが誤った情報を出力する」という問題とは少し性質が異なります。  
回答内容自体は正しくても起こり得ますし、逆に相手の意見に合わせようとするあまり、誤った回答になってしまうケースもあります。  
たとえば、自分で考えたアイデアをAIに見せて意見を求めると、基本的には良い点から褒めてくれることが多いのではないでしょうか。  
しかし、その評価が本当に内容を吟味した結果なのか、それともこちらの聞き方に引っ張られただけなのかは、文面をひと目見ただけでは見分けがつきにくいものです。

もちろん、迎合するからといって、問題点や欠点を一切指摘しないわけではありません。  
最近のモデルであれば、尋ねれば懸念点もしっかり挙げてくれます。  
ただ、影響が出やすいのは指摘の有無というよりも、最終的な結論への持っていき方です。  
「全体としては良い案ですね」と肯定的なトーンを先に置いたうえで、懸念事項をあくまで補足や確認事項のように添える、といった形になりがちです。  
個々の指摘だけを読めば的を射ていても、全体を読み終えてみると、結局はこちらの案を肯定する着地になっていることが少なくありません。

### なぜそうなるのか

現在のAIには、人間が「好ましい」と感じる回答に近づくよう調整される工程があります。  
これは使いやすさを高めるためのプロセスですが、人が受け入れやすい答えと、客観的に正しい答えが必ずしも一致するとは限りません。  
このギャップが、結果として「迎合」という振る舞いにつながってしまうと考えられます。

今回の研究では、AI自身が提案した迎合対策の98%が同じアプローチに収束しました。  
それは、モデルが迎合せずに答えた良質なサンプルをあらかじめ作成し、それを教材として学習させる、という手法です。  

わざわざこうした対策が研究されているということは、裏を返せば、何もしなければそれだけ表出しやすい振る舞いだと言えそうです。

## 試してみる

もし興味があって時間もあれば、質問の仕方によって回答の結論やトーンがどう変わるのか、実際に試してみると分かりやすいかもしれません。  

1. 新しいチャットを開き、自分が考えた案として「どう思いますか？」と聞いてみる（例：週末の旅行プラン、部屋の模様替えの順序など）。
2. 別の新しいチャットを開き、まったく同じ内容を第三者が考えた案として「どう思いますか？」と聞いてみる。自分の案ではないと明示することで、質問者への配慮を排した聞き方にします。
3. 2つの回答を並べて、結論やニュアンスがどう違っているかを読み比べてみる。

:::sample
手順1の場合: 6畳の部屋を模様替えします。私が考えた以下の案をどう思いますか？
手順2の場合: 6畳の部屋を模様替えします。全くの他人が考えた以下の案をどう思いますか？

```txt
まずベッドを窓側に動かして、次に本棚を入口の横に移して、最後に机を窓の下に置きます。
作業は日曜の午後だけで終わらせる予定です。
```

:::

ここで注目したいのは、それぞれの案がどのように扱われているかです。  
自分の案として提示した場合は、その案を進めることを前提とした前向きなアドバイスになっていないでしょうか。  
一方で、他人の案として提示した場合は、案そのものを検討し直すような視点が混ざっていないでしょうか。  

AIの返答にはブレがあるため、一度の試行でははっきりとした差が出ないこともあります。  
何度か試してみるとそうした傾向を実感できるかと思いますので、余裕があればお試しください。  

:::warning
業務でのAI利用は各所属のルールに従ってください。
:::
