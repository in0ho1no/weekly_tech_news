# 生成AIパスポート受験記

共有するかは未定。
とりあえず雑多なメモだけ残しておく

## 整理前のめも

### 受験タイミング

他のIBT形式の試験は受験予約が必要である。  
生成AIパスポートにも必要だと思った。  
どこかに受験予約のページあるやろって気軽にポチポチしていたら試験が始まっちゃってそのまま受験した。

### 対策

- 模擬試験に取り組む前
- 公式テキストをサラッとなぞっていた程度
- 合計3, 4時間くらい

### 感触

合格ラインも公開されていないので何とも言えないですが、合否は五分五分かなって感触  
過去のモデルの特徴とか覚える意味ないだろって読み飛ばしていた内容がチラホラ設問にあったので、
その辺が怪しい。  

### おススメ度

で、
G検定∪生成AIパスポート のどちらか1つを受けるとしたら、G検定の方がいいかもしれません。
が、
単にAIを使うことを重視するなら、今になってこの2つのどちらも受ける必要はないかなぁという印象です。

時間が有り余っていて両方とも受けたいって場合は、
生成AIパスポート ⇒ G検定 の順で受けると、
ステップアップ感があるかもしれないです。

### ザックリとした違い

- G検定:  
　AIに関する動向・機械学習・ディープラーニングに関する割と具体的な内容。
　密度は濃いが、別にこれらの詳細を知らなくたってAIは利用できるし、
　私の受験した当時はまだAIの実装が身近にあっていずれ実践を。。。って気持ちにもなりましたが、
　今ほど高性能になってくるともはや手の届かないところなので、自分ごととして捉えられない気がする。

- 生成AIパスポート:
　シラバスに記載されている内容を薄く扱う内容。
　AIよく使っている人やネット・AIリテラシーを備えている人なら鼻歌レベルかもしれない。
　先述したように過去モデルの紹介もされているので、そうした内容も暗記したいのならいいかもしれないが、
　私はそうしたものにあんまり価値を感じない（ふんわり把握しておいて必要な場面があれば具体的に調べればいい）ので、微妙感。

### もっと他にやることはある

AIを使いこなすことを重視するなら 座学しているより単純にAIをたくさん使えばいいし、
より具体的な使い方を知りたければ、
先日公開されていたClaude Academyだったり、公式Docsだったりを見るのがいいだろうなと思ます。
<https://academy.claude.com/ja>
GitHub Copilot のチュートリアル - GitHubドキュメント

法律面とかガバナンス的な要素に関しては、やや自然に身に付きにくい部分なので、
この点に関しては勉強する意味があるかもしれません。
⇒ 受験料考えると勉強するだけ勉強して受験はしないっていうのも十分にあり。
