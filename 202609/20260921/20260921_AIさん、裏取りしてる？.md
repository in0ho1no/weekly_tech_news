# そのAI、調べてから答えていますか

## きっかけ

### トラフィックの半分以上が、人間以外に

2026年8月6日に行われたCloudflareの決算説明会にて、CEOのマシュー・プリンス氏が次のように発言しました。  

> 人類の歴史上初めて、第2四半期に当社のネットワークを流れたトラフィックの50%超が、人間によるものではなくなった。

こうした機械的なアクセスの中には、チャットAIが回答を作成するためにWebを調べに行くトラフィックも含まれています。  
一見すると遠い世界の話のように思えるかもしれませんが、私たちが普段利用しているチャットAIの裏側でも、まさに同じことが起きています。  

今回は、この「AIが調べてから答える」仕組みについて、身近な視点から整理します。  

- AIが答える前にWebを調べに行く仕組みとその効果
- AIが実際に調べてから答えたのかどうかを確かめる方法
- もし調べていなさそうな場合の頼み方

:::source
・More Than Half of Cloudflare's Network Traffic Is No Longer Human.（The Motley Fool、2026年8月7日）
<https://www.fool.com/investing/2026/08/07/more-than-half-of-cloudflares-network-traffic-is-n/>
:::

### 数字の補足

CloudflareはWebサイトの配信やセキュリティを支える米国のインフラ企業であり、世界中の数多くのWebサイトが同社のネットワークを経由しています。  
なお、冒頭の数字はあくまで同社のネットワーク内で観測された範囲のものであり、インターネット全体を網羅した統計ではない点には留意が必要です。  

プリンス氏は同じ説明会の場で、AIエージェントによるリクエストが増え続けている点についても言及しました。  
また同氏は2026年3月の講演において、「人間がカメラを1台購入する際にはせいぜい5サイト程度を比較するのに対し、AIエージェントはその1,000倍にあたる5,000サイトものページを参照することもある」といった例えを紹介していました。  

:::source
・Online bot traffic will exceed human traffic by 2027, Cloudflare CEO says（TechCrunch、2026年3月19日）
<https://techcrunch.com/2026/03/19/online-bot-traffic-will-exceed-human-traffic-by-2027-cloudflare-ceo-says/>
:::

## AIは答える前に調べに行く

### 覚えている知識に、調べた情報を足す

一般的なAIは膨大なテキストデータから学習していますが、その学習が完了した時点より後に起きた出来事は、基本的に知識として持っていません。  
そのため従来のAIでは、直近の出来事に関する質問に対して「答えられない」としたり、事実とは異なるもっともらしい回答（いわゆるハルシネーション）を返してしまったりすることがありました。  

しかし現在のチャットAIの多くは、質問を受け取ったあとに自らWebを検索し、見つかったページを参照しながら回答を組み立てられるようになっています。  
これにより最新の情報を取得できるだけでなく、自身が保持している知識が正しいかどうかを照合する「裏取り」の役割も果たしています。  

人間が何か調べものをする場合、目を通すのはせいぜい数サイト、多くても10〜20サイト程度が一般的ではないでしょうか。調べる対象が増えるほど、集中力を保つのも難しくなってきます。  
一方、AIであれば同等かそれ以上の情報量を、ごく短時間で確認・整理してくれます。  

こうした検索機能の効果は、開発元の技術レポートなどにも示されています。  
たとえばOpenAIが2025年8月に公開したGPT-5の技術資料（System Card）では、検索機能を利用する設定と利用しない設定の双方で回答のエラー率を測定しており、いずれも前世代モデルから大幅に低下したと報告されています。  
あわせて同資料では、検索を通じて最新情報を参照する訓練と、モデルが元々持っている知識だけで答える際の誤りを減らす訓練の双方に取り組んだと説明されています。  
このようにWeb検索を併用できるようになったことは、AIの回答における誤りが減った大きな要因の一つと言えそうです。  

:::source
・GPT-5 System Card（OpenAI、2025年8月13日）
<https://cdn.openai.com/gpt-5-system-card.pdf>
:::

### 調べたかどうかを確かめる

現在提供されている多くのAIサービスでは、AIがWeb検索を行った場合、その形跡が回答画面に残るようになっています。  

- 回答の文中や末尾に、情報源（出典）へのリンクが添えられている
- 回答の前後や生成プロセスに「Webを検索しました」といった表示が出る

表示の仕様はサービスによって異なりますし、今後のアップデートで変わる可能性もあります。  
ただ共通しているのは、「Webを調べた場合には、どこを参照して答えたのかを利用者が確認できるようになっている」という点です。  

一方で、AIがいつでも必ずWebを調べてから答えてくれるとは限りません。  
検索が実行されるかどうかは、主に以下のような条件によって左右されます。  

- 利用しているサービスやモデルの種類
- Web検索機能のオン・オフなどの各種設定
- 質問の内容（あらかじめ学習済みの知識だけで十分答えられるとAIが判断した場合は、検索が行われないことがあります）

少し厄介なのは、実際にWebを調べた場合でも、調べずに答えた場合でも、AIは同じように自信ありげな口調で回答してくる点です。文面の雰囲気だけから、裏取りが行われたかどうかを見極めるのは困難です。  

そのため、回答の文章とにらめっこして疑うよりも、まずは「検索した形跡があるかどうか」を確認してみるのが手軽でおすすめです。  
もし形跡が見当たらなければ、「Webで検索して教えて」と改めて指示を出すこともできます。  
ただし注意したいのは、検索した形跡があるからといって、その回答内容が100%正しいと保証されるわけではない点です。必要に応じて添えられたリンク先を開き、AIが参照元の内容を正しく解釈して回答に反映しているかを確認することも大切です。  

## 試してみる

もし興味があって時間もあれば、チャットAIで試してみるといいでしょう。  

1. 最近の出来事やトレンドについて、普段どおりに質問してみる。
2. 返ってきた回答に、参照リンクや検索した形跡があるかを確認する。
3. 形跡が見当たらない場合は、「Webで調べて、出典のリンクを添えて答えて」と頼み直してみる。
4. 提示された出典リンクを1つ開いてみて、回答の内容と合致しているかを照らし合わせてみる。

:::sample
手順1の例: 「この秋に公開される映画で、話題になっている作品を教えてください。」
手順3の例: 「Webで最新情報を調べて、出典のリンクを付けて答えてください。」
:::

最新のAIサービスであれば、手順1の段階で自動的に検索して答えてくれるケースも増えています。  
その場合は手順3をスキップして、手順4へ進んでみてください。  
初回で検索が行われなかった場合でも、頼み直す前と後とで、挙げられる作品のラインナップや情報の鮮度に違いが現れることがあります。  

:::note
検索機能が備わっていないサービスや、設定で機能をオフにしている場合は、「リアルタイムの情報は調べられません」と返答されたり、実在しない（開けない）リンクが生成されたりすることがあります。
手順4で実際にリンクを開いてみることで、そうした挙動の違いにも気づきやすくなります。
:::

出典がきちんと付いていれば、気になった部分を自分自身の目で確かめることができます。  
「調べてから答える」AIの大きなメリットは、最新の情報が得られる点だけでなく、回答の根拠を私たち自身がたどれる点にもあると言えます。  

:::warning
なお、業務で生成AIを利用する際は、所属組織や企業の定める利用ルール・ガイドラインに従ってください。
:::
