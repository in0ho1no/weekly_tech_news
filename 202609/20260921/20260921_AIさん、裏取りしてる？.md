# そのAI、調べてから答えていますか

## きっかけ

### トラフィックの半分以上が、人間以外に

2026年8月6日、Cloudflareの決算説明会で、CEOのマシュー・プリンス氏が次のように述べました。  

> 人類の歴史上初めて、第2四半期に当社のネットワークを流れたトラフィックの50%超が、人間によるものではなくなった。

この機械によるアクセスの一部は、チャットAIが回答を作るためにWebを調べに行くものです。  
遠い世界の数字に見えますが、手元のチャットAIでも同じことが起きています。  

今回は、この仕組みを身近な側から整理します。  
読み終えると、次の3点が分かります。  

- AIが答える前にWebを調べに行く仕組みと、その効果
- AIが調べてから答えたのかどうかを確かめる方法
- 調べていなかったときの頼み方

### 数字の補足

Cloudflareは、Webサイトの配信やセキュリティを支える米国企業で、世界中の多くのサイトが同社のネットワークを経由しています。  
冒頭の数字は同社のネットワークから見えた範囲の話で、インターネット全体の統計ではありません。  

プリンス氏は同じ場で、AIエージェントからのリクエストが増え続けていることにも触れています。  
3月の講演では、人がカメラを買うなら5サイトほど見比べるところを、AIエージェントはその1,000倍、5,000サイトを見に行くこともある、と例えていました。

## AIは答える前に調べに行く

### 覚えている知識に、調べた情報を足す

AIは大量の文章から学習していますが、学習した時点より後の出来事は知識に含まれていません。  
以前は、この範囲の質問には答えられないか、もっともらしい誤りを返してしまうことがありました。  

現在のチャットAIの多くは、質問を受けたあとに自分でWebを検索し、見つけたページを読んだうえで回答を組み立てられます。  
最新の情報を取りに行けるだけでなく、覚えている内容が合っているかを確かめる裏取りにも使われます。  

人が調べものをする場合、見比べるのは数サイト、多くても10〜20サイトほどでしょう。  
数が増えるほど注意力は続かなくなります。  
AIは同じか、それ以上の量を短時間で確認してきます。  

この効果は開発側の資料にも表れています。  
OpenAIは2025年8月公開のGPT-5の資料で、検索を使う設定と使わない設定の両方で回答の誤りの率を測り、どちらも前の世代から大きく下がったと報告しています。  
あわせて、検索で最新情報を得る訓練と、覚えている知識だけで答えるときの誤りを減らす訓練の両方に取り組んだ、と説明しています。  
検索できるようになったことは、AIの誤りが減った要因の一つです。  

:::source
・GPT-5 System Card（OpenAI、2025年8月13日）
<https://cdn.openai.com/gpt-5-system-card.pdf>
:::

### 調べたかどうかを確かめる

現在の多くのサービスでは、AIがWebを調べた場合、回答に形跡が残ります。  

- 回答の中や末尾に、出典のリンクが付いている
- 回答の前後に「Webを検索しました」のような表示が出る

表示の仕方はサービスによって異なりますし、今後変わる可能性もあります。  
共通しているのは、調べた場合には、どこを見て答えたのかを利用者がたどれるようになっている点です。  

一方で、AIがいつも調べてから答えるとは限りません。  
検索するかどうかは、次のような条件で変わります。  

- 使っているサービスやモデル
- 検索機能のオン・オフなどの設定
- 質問の内容（覚えている知識で答えられると扱われた質問では、検索が行われないことがあります）

調べた場合も、調べなかった場合も、回答は同じ調子の文章で返ってきます。  
文面の自信の度合いからは区別がつきません。  

文章を疑いながら読むよりも、まず形跡があるかを見るほうが簡単です。  
形跡が見当たらなければ、調べるように頼むことができます。  

## 試してみる

もし興味があって時間もあれば、普段使っているチャットAIで確かめてみてください。  

1. 最近の出来事について、普通に質問する。
2. 回答に、出典のリンクや検索した形跡があるかを見る。
3. 形跡がなければ、Webで調べて出典を付けるように頼み直す。
4. 付いてきた出典を1つ開いて、回答の内容と合っているかを確かめる。

:::sample
手順1の例: この秋に公開される映画で、話題になっている作品を教えてください。
手順3の例: Webで調べて、出典のリンクを付けて答えてください。
:::

最近のサービスでは、手順1の時点で検索して答えてくることも多いです。  
その場合は手順3を飛ばして、手順4へ進んでください。  
検索しなかった場合は、頼み直す前後で、挙がる作品や情報の新しさに違いが出ることがあります。  

:::note
検索機能がないサービスや、機能をオフにしている場合は、「調べられない」と返ってきたり、開けないリンクが付いてきたりすることがあります。
手順4でリンクを実際に開いてみると、その違いも分かります。
:::

出典が付いていれば、気になった部分を自分の目で確かめられます。  
調べてから答えるAIの良さは、新しい情報が得られることに加えて、答えの根拠をたどれることにもあります。  

:::warning
業務でのAI利用は各所属のルールに従ってください。
:::
