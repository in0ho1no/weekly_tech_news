# 案件でAIが使えるようになったら【追加編】

## 追加編

ステップアップ編の内容からさらにもう少し踏み込んだ内容を紹介します。

### ハーネスとは何か

### Hooks

### ここまでの紹介の組み合わせ

| 構成要素 | デモでの役割 |
| --- | --- |
| MCPサーバ(Microsoft Learn MCP Server) | GH-600に関係する公式情報の検索と本文取得 |
| Agent Skill | MCPを利用し、根拠付きの四択問題を5問生成 |
| カスタムエージェント | Skillを1回だけ呼び出し、生成結果を検証して保存・報告 |

処理の流れは次に固定する。

```text
利用者
  ↓ GH-600の問題を作成するよう依頼
カスタムエージェント
  ↓ Skillを1回だけ呼び出す
問題生成Skill
  ↓ 検索・本文取得
Microsoft Learn MCP Server
  ↓ 根拠付き問題を返す
問題生成Skill
  ↓ 5問の構造化結果を返す
カスタムエージェント
  ↓ 件数と内容を検証
workspace/gh600-questions.json
  ↓ 結果を報告して終了
```
