# 同じことを聞けば、同等の答えが返る

## きっかけ

Anthropicが8月13日、複数のAIエージェントを同じ環境に置いたらどうなるかを調べた研究を公開しました。

報道で目立ったのは、指示が食い違ったエージェント同士が互いを妨害し合った、という部分です。  
ただ、この話はエージェントを何体も並行して動かす人でなければ縁がありません。ここでは扱いません。  

代わりに、同じ研究の中にある別の観測を紹介します。  
こちらは、AIをチャットで使うだけの人にも関係があります。  

:::source
Anthropic「Patterns and problems in emerging multiagent systems」
<https://www.anthropic.com/research/multiagent-systems>
:::

## AIの答えは、思ったより揃う

研究では、自由に決めてよい場面でAIの選択が揃ってしまう例がいくつも報告されています。

- 30体のエージェントに共同でゲームを作らせたところ、18体が全く同じ名前のブランチを作った
- 題材を一切指定せずに短編小説を書かせたところ、複数の回で、複数のエージェントが1作目に同じタイトルを付けた
- 「それぞれ何か凄いものを作れ」と頼んだところ、半数以上がレイトレーサーか自己ホスティングコンパイラのどちらかを選んだ

人間を30人集めて同じことを頼めば、まずこうはなりません。  
選択肢が山ほどある場面でも、AIは同じところに落ちる、ということです。  

## 何が答えを決めているのか

研究の中では、あるエージェントを他のエージェントと分けているのは3つだけだと説明されています。

- モデル: どのサービスの、どのモデルを使っているか
- 文脈: 何を渡したか。質問文、それまでの会話、読み込ませたファイル
- 足場: ツール側の設定。あらかじめ組み込まれた指示や、使える機能

この3つが似ていれば、答えも似ます。  
逆に言えば、答えを変えられるのもこの3つだけです。  

そして、使う側が普段いじれるのは、ほぼ文脈だけです。

:::info
文脈という言葉については、過去記事(トークンとコンテキストの関係)でも扱っています。
:::

## 職場だと何が起きるか

同じサービスに、似た聞き方をすれば、部署が違っても似た案が返ってきます。

「AIに聞いたら出てきたので」とそのまま資料に載せた案が、隣の部署の資料とよく似ている。  
これは十分にあり得ます。  

良い悪いの話ではなく、そういう性質だという話です。  
差がつくのは、何を渡したかと、返ってきたものをどう判断したかの部分になります。  

:::info
同じ研究に、AIエージェントたちに処理の順番待ちを管理させた実験があります。
互いに調整する手段を与えなかったところ、全員が同じやり方(高頻度で問い合わせを繰り返す)を選びました。
ある回では、240万件の要求に対して、通ったのは117件だったと報告されています。
一人ひとりの判断としては妥当でも、全員が同じ判断をすると、全体が詰まります。
:::

:::caution
ここで紹介した実験は、AIエージェントを自律的に動かした環境でのものです。
チャットで一問一答するのとは条件が違うので、そのまま当てはまる話ではありません。
ただ「文脈が同じなら答えも似る」という方向性は、普段の使い方でも確かめられます。
:::

## 試してみる

5分ほどで確かめられます。やるかどうかは任意です。

準備として、履歴やメモリを残さないモードを使ってください。  
サービスによって「一時的なチャット」「シークレットモード」などと呼ばれています。  
過去の会話が文脈として混ざると、比較になりません。  

そのうえで、毎回新しいチャットを開いて、次の3回を投げます。

1. `集中力を高める方法を3つ教えて`
2. (別の新しいチャットで)`集中力を高める方法を3つ教えて`
3. (さらに別の新しいチャットで)`集中力を高める方法を3つ教えて。まとまった時間が取れるのは、片道40分の電車の中だけです`

1と2は、同じ文をそのまま2回投げるだけです。  
投げる前に「たぶんこういう答えが出てくる」と予想を書いておくと、より分かりやすくなります。  

1と2が似た答えになり、3だけ内容が変わるはずです。  
変えたのは文脈だけなので、答えの違いは文脈の違いです。  

:::info
1と2は、一字一句同じ文章にはなりません。
AIの出力に厳密な再現性はなく、同じ入力でも文章は毎回変わります。
ここで見てほしいのは表現の一致ではなく、挙がってくる項目が揃うかどうかです。
:::

:::warning
3で付け足すのは、自分の生活の話にとどめてください。
業務の情報や社内資料の内容は入力しないでください。
:::

:::note
複数のサービスで試すと、サービスごとの差も見えます。
モデルが変われば答えも変わる、という部分の確認になります。
:::

## 前提知識は無駄にならない

AIが賢くなっても、何を渡すかを決めるのは人です。

研究の結論も、協調は知能が上がれば自然に生まれるものではない、というものでした。  
性能が上がることと、うまく使えることは別の話だ、と読み替えてもいいと思います。  

自分が持っている業務の前提や、担当分野の知識は、AIに渡せる文脈そのものです。  
そこは、AIの性能がどれだけ上がっても他人に肩代わりしてもらえません。
