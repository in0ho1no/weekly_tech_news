# 週報の点検デモ

## 目的

利用者がチャットに貼り付けた架空の作業メモから、日本語の週報を作る。
これは点検機能を試すための不完全なサンプルであり、業務用のSkillではない。

## 作業範囲

- 入力には、チャットに貼り付けられた作業メモだけを使う。
- ファイルの読み取り・変更、コマンド実行、外部サービスへのアクセスは行わない。
- 作業メモにない事実は追加しない。
- 結果はチャットに返す。

## 手順

1. 作業メモから、完了したこと、未完了のこと、次の予定を抽出する。
2. 重要な項目を適切に選び、ほどよい長さに整理する。
3. 「完了」「未完了」「次の予定」の順にまとめる。

## 出力形式

- 結果は必ずMarkdownの表だけで返す。箇条書きは使わない。
- 結果は必ずMarkdownの箇条書きだけで返す。表は使わない。
